# E-commerce-order-Dataset
Sales Analysis Dashboard using Power BI, including data cleaning, data modeling, DAX measures and interactive visualizations.

Problem Overview:
This Project focuses on analysing E-commerce sales data using Microsoft Power BI. The main objective of this project is to transform raw data into meaningful
insights through data cleaning, Data Modeling, DAX calculations, and interactive visualizations.

The dashboard helps to understand sales performance, customer behaviour, product categories, sales trends, and target achievements. It provides a clear overview 
of business performance and supports data-driven decision-making.

Project Objectives:
- Analyse overall sales performance.
- Identify top-performing product categories.
- Understand customer purchasing behavior.
- Compare actual sales with sales targets.
- Analyse sales performance across different regions and sales teams.
- Identify important business trends and patterns.
- Create interactive dashboards for better decision-making.

Tools and Technologies Used:
- Microsoft Power BI - Data visualization and dashboard creation.
- Power Query - Data cleaning and transformation.
- Dax(Data Analysis Expressions) - Calculations and measures.
- Data Modeling - Creation relationships between multiple tables.
- Microsoft Excel - Dataset handling and preparation.

  Dataset Description:
  The project consists of three main tables:
  1. Orders Table: Contains order-related information, sales details, dates, and sales representatives.
  2. Customer Tables: Contains customer-related  information and customer details.
  3. Sales Target Table: Contains sales target information used to compare target and actual performance.

  Project Workflow:
  1. Data Cleaning and Transformation
  - Removed inconsistencies and prepared the dataset.
  - Checked and formatted data and other data fields.
  - Combined first name and last name to create the Sales Manager column.
  - Prepared data for further analysis using Power Query.
 
    Data Modeling:
    - Created relationships between Orders, Customers, and Sales Target Tables.
    - Established connections using Customer ID and Sales POC.
    - Organized the data model for accurate analysis.

    DAX Calculations:
    - Created calculated columns and measures.
    - Calculated Actual Sales.
    - Calculated Total Target.
    - Used DAX to support sales performance analysis.

    Dashboard Development:
    Created interactive Power BI visualizations to analyse:
    - Sales Performance.
    - Customer and category analysis.
    - Sales trends.
    - Geographical sales distribution.
    - Sales team performance.

    Key Features:

    - Category-wise sales insights.
    - Geographical sales analysis.
